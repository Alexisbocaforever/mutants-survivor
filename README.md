# Mutants Survivor

Juego de supervivencia top-down desarrollado en C++ con Qt.
El jugador debe sobrevivir oleadas de enemigos usando distintas armas
(pistola, escopeta, FAL, lanzallamas, granadas, lanzacohetes, lanzasierras),
comprando mejoras en tiendas y avanzando de nivel hasta enfrentar al jefe final.

## Compilación
Requiere Qt 6 y qmake. Abrir MutantsSurvivor.pro en Qt Creator y compilar en modo Release.
